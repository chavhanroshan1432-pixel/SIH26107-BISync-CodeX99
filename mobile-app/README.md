# Mobile App

React Native / PWA mobile application for BISync.

## Features

- Multilingual BIS assistant
- Search Indian Standards
- BIS services information
- Voice-based interaction
- Hindi, English and Marathi support
- Mobile-friendly interface

## Planned Technologies

- React Native
- JavaScript
- REST API
- Bhashini API
- FastAPI Backend
